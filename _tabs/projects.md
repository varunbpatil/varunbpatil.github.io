## [Temporal Lens](https://github.com/varunbpatil/temporal-lens)

A search engine for [Temporal](https://temporal.io) workflows powered by [OpenSearch](https://github.com/opensearch-project/opensearch).

## [Go + React Template](https://github.com/varunbpatil/go-react-template)

A modern Go + React end-to-end type-safe project template using modern frameworks like [Buf Connect](https://connectrpc.com) and [TanStack Query](https://tanstack.com/query/latest).

## [Typst Go](https://github.com/varunbpatil/typst-go-wasm)

A Go wrapper for the [Typst](https://typst.app) typesetting system using Rust and WASM. The only CGo-free Go wrapper for Typst that doesn’t require installing the Typst CLI. Featured on [best-of-typst](https://github.com/YDX-2147483647/best-of-typst).

## [Testify](https://github.com/varunbpatil/testify)

A fork of the popular stretchr/testify package with a Suite implementation that supports parallel tests.

## [Go Enum](https://github.com/varunbpatil/go-enum)

A zero-dependency code generator for Go enums for type-safe enum handling.

## [Breathing Techniques](https://github.com/varunbpatil/breathing-reminder)

A GNOME Shell Extension to practice different breathing techniques.
